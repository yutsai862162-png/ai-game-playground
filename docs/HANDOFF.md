## 2. 已完成的遊戲功能

### 2.1 畫面流程
標題 → 開場字卡與劇情 → 客廳地圖自由探索 → 出門 → 超市場景（選擇題）→ 回家交給媽媽 → 結局 → 章節完成畫面（評價、成就、第二章預告）→ 返回標題，或回客廳閒晃。

### 2.2 操作（⚠️ 總監已確認「很順手」，請保留）
| 功能 | 實作重點（`game/game.js`） |
|---|---|
| 虛擬方向鍵（左下） | 感應區是看得見的按鍵的 1.5 倍大，搖桿頭會跟著手指。方向判斷有遲滯，避免斜角抖動：已經在走一個方向時，手指要明顯偏 1.35 倍才換軸。死區約半徑 16%。用 Pointer Events 加 `setPointerCapture` |
| 按住持續移動 | 走完一格會無縫接下一格，多出來的進度帶到下一格。`MOVE_TIME = 0.15` 秒走一格 |
| 輕點只轉身 | 按到新方向未滿 `TURN_DELAY = 0.07` 秒就放開，只轉身不移動 |
| 點地圖移動 | 點空地會用 BFS 找路走過去；點人物或物件會走到旁邊並自動互動；點到人物頭部（在上一格）也算點到人 |
| 互動鍵 A（右下） | `pointerdown` 立即觸發，有按下動畫，`::before` 往外多 22px 感應範圍。靠近目標時會發光，標籤顯示「對話」或「調查」 |
| 對話前進 | 手指一碰就前進。選項出現後 280ms 內的點擊會忽略，避免誤選 |
| 鍵盤 | 方向鍵／WASD 移動；Space／Enter／Z 互動；1–9 選擇選項；Esc 關閉背包 |
| iOS 防誤觸 | 阻止頁面拖動、雙指縮放、雙擊縮放、長按選單；`touch-action: none`；處理瀏海安全區；高度用 `--app-h` 跟著 `innerHeight` 修正 |

### 2.3 劇情與系統
- **主線「幫媽媽買東西」：**
  1. 跟三位家人打招呼（0/3），媽媽叫你過去並交付購物清單。
  2. 從大門出門，到超市三回合選擇：醬油、蔥、雞蛋。
  3. 選錯會跳出家族群組的手機吐槽、畫面震動，「媽媽心情」變差，然後可以重選，不會卡死。
  4. 最後有選擇性的布丁，回家交給媽媽驗收進入結局。
- **支線「神秘消失的裝備」：** 已依第二輪總指令重寫，詳見第 6 節。
- **NPC：** 媽媽（廚房）、爸爸（坐在沙發背對看電視）、妹妹（餐桌旁，已搬出去住、回來吃飯）。
- **可調查物件：** 流理台、冰箱、哥哥房門、電視、公仔櫃、沙發、餐桌、盆栽、鞋櫃、大門。
- **演出：**
  - 視覺小說式對話框，有頭像、姓名、打字效果、選項
  - 頭頂表情泡泡、畫面震動
  - 手機群組通知、場景字卡、取得道具彈窗、成就提示
  - 用 Web Audio 合成的音效，可以靜音
- **回憶背包：** 媽媽的購物清單、神秘鞋盒、給媽媽的布丁、戰利品購物袋。
- **成就：** 裝備搶救成功、把我兒子還來（採買零失誤）、孝親布丁；另有「距離產生美感」佔位，永遠顯示鎖住。
- **存讀檔：**
  - `localStorage` 的 key 是 `otakuHero.ch1.save`，版本 `v: 1`
  - 偏好設定（音效開關）存在 `otakuHero.prefs`
  - 所有存取都包在 try/catch；無痕模式會在標題提示無法存檔
  - 存檔損壞時會提示並要求開新遊戲
  - 關鍵節點自動存檔；右上有手動存檔；回標題前會確認並自動存檔
- **錯誤處理：** `window.onerror` 和 `unhandledrejection` 都會顯示紅色錯誤列，提供「回到標題」按鈕；主迴圈出錯會停止，不會一直洗出錯誤。
- **直式：** 會顯示旋轉提示，可以選「先用直式繼續」。

## 7. 美術素材的接入方式、尺寸與需求

### 7.1 座標系統
- 一格 `TILE = 32` 個邏輯單位，地圖 20×12 格（640×384 單位）。
- 實際畫面倍率 `G.scale`：iPhone 橫式約 1.3–1.5 倍，再乘上 `devicePixelRatio`（2–3）。所以**一格在 iPhone 上大約是 96–144 個實體像素**。
- 角色的錨點是腳底中心：`(格x*32+16, 格y*32+29)`。坐著的爸爸是 `+24`。
- 角色高度約 46–53 單位（v5），也就是約 1.5 格。

### 7.2 建議規格
| 素材 | 建議尺寸（@3x，PNG 透明） | 數量 | 對應程式 |
|---|---|---|---|
| 角色行走圖 | 每格 **96×160 px**（32×53 邏輯單位 ×3），4 方向 × 3 影格（站、左腳、右腳）| 哥哥、爸爸（另加坐姿背面與正面）、媽媽、妹妹；未來大嫂留給之後章節 | 取代 `Art.chibi(ctx, x, y, look, o)`：依 `o.dir` 選列、依 `o.moving` 和 `o.t` 選影格，`drawImage` 時腳底對齊 `(x, y)` |
